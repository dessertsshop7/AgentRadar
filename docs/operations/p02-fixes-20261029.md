## 已知限制与交付结论

- 单个 GitHub Search 查询仍受前 1000 条窗口约束；超过时保持不完整覆盖标记并继续其他查询，不承诺全量。需要更细的人工查询划分才能覆盖窗口外记录。搜索排序随上游变化，偏移续读是尽力覆盖，并非事务快照。
- 本轮默认计划的长周期、断点和失败边界由可控时钟/外部替身结合真实 PG 验证；没有运行真实全库同步或等待数天。不能将该结果称为长期线上实测。
- 自动重审覆盖 GitHub 返回的 SPDX/简介/主题，尚不单独检测 SPDX 不变时许可正文的变化；需要持续保留资料审核边界。
- 历史刷新留证依赖本机大体积快照和起始数据库，不承诺新 clone 自带这些数据。归档文本不可当成当前维护命令执行。
- 维护接口仍依赖本机/容器与数据库权限；没有引入账号、企业审计、向量检索或其他未来阶段能力。
- 远端 CI 在推送后才能判断，不把本地通过写成 Actions 已通过。
