# 用户旅程

状态：P01 假设流程，2026-10-17。事件名为未来计划，当前没有采集；事件口径见 [指标字典](metrics.md)。
P01 只有发现、详情、固定助手交互与工程状态；以下真实试用/反馈/支持均未实现。

## J01 工具发现与理解

触发：初学者或产品运营知道想处理的任务，但不知道工具名称。关联 US01–06、F01/F02。

| 步骤与页面 | 用户决策/所需信息 | 数据来源与阶段 |
| --- | --- | --- |
| `/` → `/discover` | 选择浏览目录或进入助手；首页直接进入发现，避免两份工具列表 | P01 重定向；MVP 同一入口 |
| 搜索、组合场景/门槛 | 是否还有足够候选？名称、摘要、标签、技术条件 | P01 静态虚构目录；P02 候选为已审核真实目录 |
| 打开 `/tools/[slug]` | 能做什么、不能做什么？是否可接受依赖和未知项？ | P01 概念解释；P02 候选为人工中文解释+原始来源 |
| 核对来源 | 信息是否支持当前决策？原文位置、版本、核实时间、许可证 | MVP 来源记录；P01 只显示“虚构案例、无真实仓库” |
| 下一步：助手或试用指引 | 还需选型则进 `/assistant?tool=...`，已有候选则读试用条件 | P01 演示助手；MVP 指引在详情 |

失败与恢复：无匹配保留查询并清除条件；目录读取失败可重试；详情不存在可回发现；未知信息允许暂不选择。
退出：用户可在任意步骤离开；不推断已经尝试。URL 保存搜索条件，返回/刷新可重放；助手草稿当前不保存。
成功：用户能复述用途、限制与下一步。未来可观测 `discovery_view → search_applied → tool_detail_view → source_link_clicked`，
这些仅反映行为；理解程度需要任务复述或测评反馈，不能从停留时长断言。

## J02 业务需求选型与尝试

触发：产品运营要解决一个具体工作问题，需要结合技术条件选择候选。关联 US07–14、F03/F04/F05。

| 步骤与页面 | 决策/所需信息 | 数据来源与阶段 |
| --- | --- | --- |
| 发现或详情 → `/assistant` | 是否已有待评估工具？带入工具上下文，不代替输入需求 | P01 通过 `tool` 参数选初始场景 |
| 输入任务、选择场景/技术条件 | 是否足够明确？失败时保留输入、聚焦错误 | P01 本地内存表单；后续 MVP 需服务端校验 |
| 查看候选与规则依据 | 候选是否满足硬约束？哪些未知条件要先确认？ | P01 固定映射，文本不做语义匹配；后续 MVP 真实规则/目录版本 |
| 读详情的试用前检查 | 是否有环境、权限、预算和可用的样本？ | 后续 MVP 来源明确的指引；P01 是概念性清单 |
| 打开官方入口并离站尝试 | 按官方说明自行操作；可中止，网站不执行命令 | 后续 MVP 外链点击事件；外部实际运行过程默认不可见 |
| 返回原工具/任务反馈尝试 | 只是点击、已经尝试、未继续，还是已有结果？ | 后续 MVP 用户自报，关联 `trial_id` |
| 反馈结果并说明证据 | 成功/失败/尚无结论；自报或有经核实证据？ | 后续 MVP 结果记录；带证据的核验流程后续再定 |

失败与恢复：空需求指出具体字段；无匹配时补充条件；不支持的任务不装作理解；配置受阻可以先记录失败再寻求支持。
退出：离站后没有反馈的记录标“结果未知”，不能归入成功或失败；匿名 ID 的跨设备恢复需要另定方案。
P01 不保存文本/草稿/结果，表单明确提醒离开或刷新后清除；不承诺跨页面恢复。
成功：实际完成用户任务且有明确结果反馈。未来事件为
`assistant_request_submitted → candidate_view → trial_guide_view → tool_external_link_clicked → trial_feedback_submitted → outcome_feedback_submitted`。
仅最后的 `outcome=success` 且关联有效尝试可进入自报成功口径；原型展示结果不计入这个漏斗。

## J03 部署排障与知识反馈

触发：技术支持收到“部署失败”或“工具不可用”的求助。关联 US11/18/21/22、F08/F11。

| 步骤与页面 | 决策/所需信息 | 数据来源与阶段 |
| --- | --- | --- |
| `/status` 查看平台是否可用 | 平台链路故障还是外部工具故障？后端、数据库、请求 ID | P00 真实健康接口；只能诊断 AgentRadar 自身链路 |
| `/support` 选择工具与问题 | 是否提供系统、版本、部署方式、复现步骤？ | 增强版，当前路由不开放 |
| 提交脱敏环境和错误 | 信息是否足够？是否含密钥/个人内容，应先移除 | 增强版用户输入；不自动上传机器日志 |
| 查看有来源的检查建议 | 原因是否被证据支持？步骤能否安全回退？ | 增强版知识库/官方文档；模型辅助另做评估 |
| 用户自行操作并验证 | 原故障是否消失？是否产生新问题？ | 用户环境；未经验证不能标已解决 |
| 反馈、审核并沉淀知识 | 是否可复现、适用哪个版本/环境？ | 增强版审核记录；企业协作另依赖权限 |

失败与恢复：来源不足先追问；无法判断则转人工或暂停；建议失败保留上下文，允许撤回敏感附件并走新的检查路径。
退出：未返回验证的会话为结果未知，不以“建议已生成”关闭问题。
成功：用户确认同环境下原故障不再出现，记录证据等级；审核后可作为带版本知识复用。
未来事件 `support_request_submitted → support_resolution_feedback_submitted`；知识发布与问题解决分开统计。
P01 不实现工单、诊断、上传、知识库或这些事件。
