# AgentRadar 基础设计规范

2026-10-17，P01。实现入口：`apps/web/app/globals.css`、`apps/web/components`。
本阶段沿用现有 CSS，不安装 Tailwind、shadcn/ui、图标包或字体包；未来有实际组件需求再评估，整体 Next.js 技术路线保持不变。

## 方向与取舍

选择“浅色工具目录”：清晰的信息层级、可见筛选、适用条件优先、克制的青绿色主色。
UI UX Pro Max 首次查询偏向社区营销/儿童字体，不适合中文工作任务；收窄查询后得到 Marketplace/Directory + Flat Design。
采用搜索优先、分类可见、平面布局和键盘反馈，舍弃营销轮播、虚构评价、卖家 CTA 与高饱和背景。
不照搬其字体/颜色：中文采用系统字体，主按钮加深至可配白字的颜色；不下载外部字体，不增加动效依赖。
实际页面就是可操作原型；P01 不额外复制一份 Figma 画布，避免规范与代码两套维护。需要交付设计源稿时再按用户指定位置创建。

## 语义令牌

颜色只在 CSS 令牌中定义，组件使用语义类，不按工具类型随意加颜色。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--background` | `#f6f8f7` | 页面底色 |
| `--surface` | `#ffffff` | 卡片/表单 |
| `--text` | `#182c29` | 主要文字 |
| `--muted` | `#52645f` | 次要文字 |
| `--border` | `#dce4df` | 非交互分隔线 |
| `--control-border` | `#7b8f87` | 输入框/选择器边界 |
| `--primary` / `--primary-hover` | `#146653` / `#0e5142` | 主按钮、选中导航、链接 |
| `--tint` | `#eaf3ee` | 选中背景/场景块 |
| `--warning` / `--warning-bg` | `#815014` / `#fff5df` | 演示提示/待核实 |
| `--danger` / `--danger-bg` | `#9b3030` / `#fff1ef` | 读取错误、字段错误 |
| `--focus` | `#1967b3` | 3px 可见焦点，偏移 3px |

正文和次要文字以 WCAG AA 普通文本 4.5:1 为目标；控件边界/焦点 3:1。
非交互卡片细线不承担状态意义；正常、错误、演示状态始终有文字，不能只靠颜色。
仅浅色主题，`color-scheme: light`；不提前建设暗色主题、主题切换或可配置主题系统。

## 排版与间距

- 字体：`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`；代码使用系统等宽字体。
- 正文 16px/1.65，次要文字 14px/1.6；最小辅助文字 12px，核心说明不小于 14px。
- 页面标题 `clamp(28px, 3.2vw, 42px)` /1.25；段标题 22px/1.4；卡片标题 19px/1.45。
- 标题 `text-wrap: balance`；段落合理限宽，完整保留中文长标题，不靠省略号隐藏关键约束。
- 间距：4/8/12/16/24/32/48/64px；圆角 6px（标签）/10px（控件）/16px（卡片）/24px（介绍块）。
- 容器最大 1200px；桌面水平留白 32px、小屏 20px。正文详情列不拉成整屏长行。

## 组件约定

| 组件 | 对应代码/类 | 规则 |
| --- | --- | --- |
| 导航 | `site-header.tsx` / `.site-nav` | 品牌回发现，发现/助手/工程状态为真实链接；当前页 `aria-current=page`；详情归发现；小屏自然换行 |
| 演示条 | `demo-notice.tsx` / `.demo-notice` | 三个产品页始终显示“演示数据”；助手另显示未连接模型；工程页不贴演示标签 |
| 卡片 | `tool-card.tsx` / `.tool-card` | 名称链接、摘要、场景/门槛、有限标签；不展示虚构 stars、用户数或采集时间 |
| 按钮 | `.button`、`.button-secondary` | 原生 button 动作/Link 导航，最小高 44px；hover/active/focus；请求进行中才禁用重复提交 |
| 输入 | `.field` / `.search-field` | 显式 label、name、说明和限制；文本输入不禁粘贴；错误 `aria-invalid` 与 `aria-describedby`，聚焦首个错误 |
| 筛选 | `.filter-panel` | 原生 select + 应用按钮；组合查询；条件反映 URL；筛选值非法给提示 |
| 标签 | `.tag`、`.badge` | 非交互信息标签不用按钮；可换行、长词可折行；类别不作为可信度徽章 |
| 状态 | `catalog-state.tsx` / `.state-panel` | 加载 role=status；错误 role=alert + 重试；空目录和无匹配分别解释；未开放是文字，不假装可操作 |

装饰图形使用简单内联 SVG（雷达品牌标记），旁边有文字时 `aria-hidden`；不使用 Emoji 冒充图标，不引入图片请求或伪造第三方品牌。

## 状态与恢复

| 状态 | 文案/行动 | 数据边界 |
| --- | --- | --- |
| 目录加载 | “正在读取演示目录…”；骨架不进入可访问树 | 正在读取静态演示 JSON，设 5 秒上限 |
| 目录为空 | “演示目录暂时没有内容”；重试读取或进入助手说明 | 文件有效但 tools 为空，不等于筛选没命中 |
| 无搜索结果 | 显示保留的条件；“清除筛选” | 已有目录但过滤后为空，不伪造替代结果 |
| 读取失败 | “演示目录读取失败”；检查网络/重试 | 不显示堆栈或原始错误；不自动重试放大故障 |
| 详情不存在 | 说明没有该页面/案例，返回发现 | 不创建虚构详情 |
| 助手字段错误 | 需求至少 10 个非空白字符，最多 500；保留输入、聚焦字段、移除上次结果 | 本地校验，不发业务请求 |
| 助手结果 | “演示交互，未连接模型”；固定规则、局限、下步检查 | 无概率分数，不声称安装/应用成功 |
| 未开放 | “规划中”说明或不显示入口 | 收藏、诊断、反馈、运营与企业能力均未实现 |

路由还有 Next.js `loading.tsx`、`error.tsx` 和 `not-found.tsx` 的安全恢复界面；不通过测试开关故意让生产代码报错。

## 响应式与可访问性

- ≥1100px：筛选栏约 224px + 双列卡片；详情/助手采用主内容 + 决策旁栏。
- 640–1099px：筛选横向分组，目录可双列；详情和助手单列，避免 768px 下正文过窄。
- <640px：导航换行、搜索与按钮可堆叠、卡片单列、动作撑满可用宽度；不使用遮挡内容的固定栏。
- Grid/Flex 子项 `min-width: 0`；URL/代码 `overflow-wrap: anywhere`；标签 `flex-wrap`，无以裁剪隐藏溢出的做法。
- 可通过 Tab/Shift+Tab、Enter、原生选择器按键完成核心流程；跳过导航链接直达可聚焦 main。
- 结果展示后聚焦结果标题；修改需求返回文本字段；没有焦点陷阱，不自动弹窗抢焦点。
- 所有交互有 `:focus-visible`；主操作、卡片入口和导航保持 44px 目标，正文内联链接保留文本语义；动画只作短时颜色/背景变化，支持 reduced-motion。
- 搜索条件可分享，需求文本不写 URL；表单提示离开会清除，P01 不承诺草稿恢复。

## 参考与审查

- UI UX Pro Max：2026-10-17 本地设计检索，采用收窄后的目录/平面布局建议，非用户调研。
- React Best Practices：服务端保留详情/外壳，只把目录加载、导航激活和表单做为客户端岛；筛选派生结果直接计算，无额外状态镜像。
- [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)：2026-10-17 获取，按可访问性、焦点、表单、URL 状态、内容溢出逐项审查；实际结果见 P01 基线。
- Context7 查询 Next.js 官方资料，并以项目已安装 16.4.2 文档核对动态 `params`、错误边界；不依据旧版本记忆替换 API。
